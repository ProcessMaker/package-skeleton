Inside the 83%

The 56 tasks, routing rules BR-30 to BR-57, deal initiation, allocation, signatures, the uploaded-file index, the notification catalog, and the two report tables. The process still needs a Nayra walkthrough, and group ids and usernames still need to be loaded.

What brings it down to 66%

Publication

The package classes, the Vue bundle, the acd_* migration, and the seed data were not installed with those assets, so a case still cannot run end to end. The Send Email task’s pm:config screenRef was stored as the named reference ${screen:credit-deal-notification-email}; the connector reads that JSON, so screen 464 still has to be selected on the task.
